# Bijli Bill Calculator

OOP-based electricity bill calculator in Python (ALCI Project 2).

## Features
- Domestic (slab) and Commercial (flat rate) customers
- GST, TV fee, late payment surcharge
- Data saved in JSON
- Terminal menu + Streamlit web app

## Run
pip install -r requirements.txt
python main.py
streamlit run app.py

## Concepts
Classes, inheritance, polymorphism, abstraction, encapsulation, composition,
custom exceptions, JSON, modules, Streamlit
